# 24点游戏求解器 (Point24-Solver)

一个功能完整的24点游戏求解器，使用回溯算法穷举所有可能的解法。

## 项目特点

- **核心算法**：使用"两数合并"的回溯策略，优雅处理括号优先级
- **完整解法**：输出标准中缀表达式，而非计算步骤
- **鲁棒性强**：正确处理除零、浮点数精度等边缘情况
- **双界面**：提供命令行和图形界面两种交互方式
- **充分测试**：包含全面的单元测试，覆盖各种情况

## 快速开始

### 环境要求

- Python 3.8+
- 无需安装额外依赖（GUI使用标准库Tkinter）

### 运行命令行版本

```bash
python src/solver.py
#按提示输入4个数字（1-13），程序会输出所有可能的24点解法。

#运行图形界面版本
python src/gui.py
#在图形界面中点击数字按钮输入，点击"求解"查看结果。

#运行测试
python -m pytest tests/
# 或者
python tests/test_solver.py
